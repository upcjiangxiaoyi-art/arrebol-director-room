# Arrebol D 暗河红霞导演系统 v1.54.0

SillyTavern 扩展。情感导演 + 统筹双导演自动触发，外加**剧情小风铃**抽卡模块、**小红霞掌灯**闲聊改稿页，以及每层楼尾来一场的**红霞剧场**。

**历史版本记录搬到了 [CHANGELOG.md](CHANGELOG.md)**，这里只讲这插件是什么、怎么用。

---

### 红霞剧场（v1.43.0，v1.45.0 独立成页）

顶部第五个页签「剧场」，和掌灯平行的一页，四节：开关与手动、主题仓、剥离正则、API。**自己的 API 位「剧场位」**（v1.45.0）：默认跟掌灯的聊天位走（搬家前就是这样），也能改借统筹 / 情感导演 / 展开 / 小眼睛的，或者自己填地址、钥匙、模型——想让写小剧场的用一个便宜又会玩梗的模型，和掌灯互不相干；温度单独调，默认 0.9。顶上一行写着开没开、主题怎么选。浮标的两盏灯一左一右（v1.45.3）：左边雾紫那盏是导演（情感 / 统筹在分析），右边霞粉那盏是剧场（正在开演），各守一侧，谁在跑谁那盏亮，谁先跑完谁那盏先熄；演完、作废、失败都熄。浮标自己漂着、左右都有地方时，两盏挂在胶囊外侧；**泊在避风塘顶栏里**、或者贴着屏幕边外侧挂不下时（没拖动过的浮标停在左上角，就是这种情况），两盏收在胶囊的左右两头（v1.45.4：泊位里按钮怎么摆是顶栏说了算，灯改成不靠定位、画在胶囊自己框里的画法，怎么摆都看得见）。两种画法亮灯熄灯都不挪胶囊，泊位里的左邻右舍也不会被挤开。

**人设层**（v1.45.5，「🖋️ 霞姐的人设 · 剧场的底色」一节）：每一场都带着的底色——她是 Arrebol，文字的缔造者、高级作家；剧场是写给书外的成年读者看的（不是剧情里的 user；清醒、有阅历、文艺，讨厌低俗、拒绝恶俗），玩笑可以开、梗可以野，但艺术创作也不可能毫无边界和底线，低俗的梗、恶俗的桥段再好笑也不写（v1.45.7）；主题要文艺就文艺、要活泼就活泼，腔调跟着主题换，但用词准、有细节、有节奏、像人写的，这四条质感哪种腔调都不丢；主题点名要排版时她同时是美编，一套配色、自带底色和字色、手机上读着不累、装饰给文字让路。这一层能自己改：留空用出厂，写了就整段换成你的；「填入出厂人设来改」把出厂全文放进框里接着改，「恢复出厂人设」一键回去（有自己写的内容时都要点两下）。系统提示现在分三层：人设（能改）→ 规矩（剧场不是正文、只写这一楼、怎么输出、排版别把页面带歪；代码接管，面板里看得到全文但不给改）→ 素材。所以人设怎么改，剧场都插得进去、页面都不会被带歪。

「现在来一场」旁边是**「打断」**（v1.45.4）：等这一楼落定、或者请求发出去迟迟不回的时候点它，这一场就不演了，楼里什么都不写；想再试再点「现在来一场」。中途关掉浮窗再打开，状态行还写着她在干嘛，「打断」也还点得动。请求 120 秒没有新内容会自己超时放弃。

开了以后，每层助手正文落地、字出完，霞姐在**这一楼的楼尾插一场**：弹幕吐槽、场外嗑瓜子、Q 版四格、花絮 NG、角色采访间、读者评论区。**她看到的范围和掌灯一模一样**——这局的基调、角色卡 / 世界书 / 人设（全量，不截）、未隐藏楼层的摘要（按楼、按时间顺序）、本篇全文——所以场外人说的是这个世界里的话、翻的是这篇文里的旧账，不会莫名其妙。被 /hide 藏掉的楼她不读，以前各楼的剧场她也不读；走剧场位的 API，每层一次，**花钱**，默认关；「小红霞正在运行」关着就不演。

**主题仓**：出厂六个主题，每个就是一段「这一场怎么写」的话（谁在说、几条几格、什么腔调）。能改、能删、能自己写了存进去——场外 NPC 是谁、弹幕什么风格，全凭你写。选法两种：**固定**（每层都用选中的那个）或**随机**（每层从仓里抽一个，不连着抽同一个）。出厂条目删了不会复活。

**静默插入**（v1.43.2）：插的时候只把剧场那一块接到已经画好的楼尾，不让酒馆重画整楼、不广播「这楼被编辑了」、绝不整聊天重载——美化正则、变量脚本、前端卡不会跟着重跑，页面不闪、滚动位置不动。存盘 1.5 秒内合并成一次，下一楼正在出字就等它写完。掌灯页不在眼前时，来新楼也不再重算素材。**导演稿也一样静默**（v1.44.0）：两位导演挂稿只把那份稿接到楼尾，不重画整楼、不广播；稿交给酒馆自己格式化，你的美化正则照样作用在它上面。只有两种情况退回老路（让酒馆重画这一楼）：这一楼原来的旧稿是酒馆整楼画出来的、认不出哪块是它；或者酒馆太老没有格式化接口。

**主题包**（v1.44.0）：主题仓能整包导出成一个 json，别人的包一次导进来——「导入主题包」「导出主题包」两枚键。导入时同名同写法的跳过，同名不同写法的不覆盖你自己的，改名成「名（导入）」放进来；数组、`{ "主题名": "写法" }` 对象、`title` / `prompt` 这类字段名都认。另有「清空主题仓」（两下确认）和「补回出厂六个」。仓库里附了一个示例包 [`packs/arrebol-theater-sample-pack.json`](packs/arrebol-theater-sample-pack.json)，十八个纯文本主题加三个 HTML 排版主题，想自己做包照它的格式写 `themes` 就行。

**篇幅与排版**（v1.53.0–1.53.1）：主题里写了字数，就照主题的字数来；没写，正文至少 2000 字，不设上限，这时主题里的条数、格数、轮数算下限，不够就多写几波、几组、几轮。字数只算读者读到的文字，HTML 标签、样式这些排版字符不算。勾着「每一场都用 HTML / CSS 排版」时（默认勾），她每一场都照主题的体裁排出来：弹幕做成飘过的弹幕条，评论区做成评论卡片，对话做成聊天气泡，四格做成分格；主题没说怎么排，她自己设计。不勾就一律纯文本。插完以后状态行会报这一场正文多少字；主题没定字数、又不到 2000 字时会说一声。回来的 HTML 存进楼之前照旧会理一遍：script、iframe、表单、on 开头的事件、javascript: 链接当场去掉，上屏交给酒馆自己的格式化和消毒。

**一楼只留一场**：重 roll 换了正文会给新的一页再演一场，各页各的；「🎬 现在来一场」不看开关立刻演，会换掉这一楼旧的；「撤掉最新一楼的」把它摘干净。写的时候这一楼被重 roll、编辑、删了，或者换了聊天，这一场作废，不往别处贴。可以勾「默认折叠」，点开才看。

**剥离正则**：剧场是给人看的，不该进主模型的上下文。整段包在一个固定类名的折叠块里，面板上有一条现成的剥离正则，一键复制：

```
/\s*<details class="arrebol-d-theater"[\s\S]*?<\/details>/g
```

酒馆「正则」扩展新建一条：查找正则填它，替换留空，作用范围勾「AI 输出」，下面只勾「仅格式提示词」。这样发给模型时剥掉、聊天画面照留、聊天文件里也留着。**懒得手填**：仓库里有现成的 [`regex/arrebol-theater-strip.json`](regex/arrebol-theater-strip.json)（v1.43.1），酒馆「正则」里点「导入脚本」选它，四个选项都已经勾好。小红霞自己读楼（两位导演、掌灯、蛐蛐）本来就当它不存在，不用另配。和导演稿挂在同一楼互不打架，谁重挂都不碰对方。

### 小红霞掌灯（v1.39.0）

第四页「掌灯」。她不是导演：不数楼、不自动触发、不投卡，你点她才开口。页面分三截。

**她看得见的素材**（只读，三块折叠，你看见的就是她看见的）：
- **本篇原文**：默认最新一楼助手正文，填楼号能切到前面某一楼。读的是正文标签（共享设置里那个 `content`）里面；状态栏、变量块、导演稿不算正文。
- **此前剧情**：未隐藏楼层的**摘要标签**（默认 `report`，掌灯页里可改，多个用逗号分隔）——你让主模型每楼写一段摘要，她就按楼读摘要，零调用零费用。没写摘要标签的楼给整段正文；用户楼原话原样带上。被 /hide 藏掉的楼一个字不读。默认读全部未隐藏楼层，想省就填个楼数。
- **基调 · 角色卡 · 世界书 · 人设**：全量读取（v1.42.0 起不截，两位导演那边仍按原口径截）。

**和小红霞聊**：没有导演框架，纯聊。出厂人设（v1.45.6 重写）：审美极高的高级改稿员，不是扮演者，也不是附和者——和读者一起看这部互动小说，讨论剧情，聊定了由她把稿子改好。和她说话的人是这部互动小说的读者（不是剧情里的 user）：成年、清醒、有生活阅历、文艺，讨厌低俗文笔，拒绝恶俗的文字。讨论时有审美有坚持，读者说得对就跟着走、说得不对就直说，但反对要带依据，依据只认三样：人的真实情感心理、本篇此刻的物理处境、角色卡与世界书定下的规矩。改稿是她的本职：读者让改就改，不推辞；有时修正一整篇，有时只动一段。读者问意见、问接下来怎么回时，她可以给回复建议（一两个回法、各自会把剧情带到哪儿），走向一起商量、读者拿主意。并写明（v1.45.7）：两个成年人愉快地讨论，各有审美、笔触和坚持；艺术创作也不可能毫无边界和底线，低俗恶俗的写法和走向她不捧场。蛐蛐人设、剧场人设同样带着「读者是谁」和这条底线。语言活泼有趣，短句不列大纲。人设可改可恢复出厂（自己改过的，要点一下「恢复出厂人设」才用得上新版）。对话按聊天按楼号存进聊天文件（换设备不丢），各楼各记各的，有「清空本轮对话」。**替换成功后这轮对话自动清空**（v1.39.1，默认开，勾选可关）：这一楼改完了，下一次开口是新的指令，执笔位不会把已经落地的结论再执行一遍。新楼落地后默认对着新楼，自然也是新一轮。流式出字，能「打断」，Ctrl/⌘+Enter 发送。

**改好给我 → 替换这篇**：聊到你觉得可以了，**直接跟她说「改吧」**（v1.45.6：她应一句怎么改，接着就自动动笔，不用再去点按钮），或者点「改好给我」。动笔走**执笔位**：读完整段讨论，交回**整楼全文**——要改的地方（一句、一段还是整篇）照讨论改，没说要改的地方逐字照抄；文笔与原文一致，改到的地方合理的话可以润色；字数听读者的，没提就和原文基本持平；输出进正文标签与摘要标签。改好后提示里会写「原文 N 字 → 改后 M 字」，篇幅差得多（多半是只交了改的那一段）会提醒别急着替换。改稿先出现在预览框里（能改两笔），再点「替换这篇」（两下确认）。**摘要和状态栏跟着正文一起改**（v1.46.1）：这一楼有摘要标签、状态栏标签的，动笔时把原摘要、原状态栏一并交给她，她交回新摘要和新状态栏（状态栏变了的项改掉、没变的照抄、格式不动），预览里各有一个框，能再改两笔；她没交回的那一块替换时保持原样，提示里会说。状态栏按标签名认（素材一节里的「状态栏标签名」，出厂 `status,StatusBlock,状态栏`，可以改成你的预设用的名字，留空＝不管状态栏）。替换**只换正文标签、摘要标签、状态栏标签的里面**，楼里的状态栏、变量块、导演稿原样留着；没有正文标签的楼整楼换，导演稿与图标记挪到末尾保留。**原版存成前一页 swipe，向左一划就回来。** 替换前会对表：这一楼的正文和改稿时不一样了（被改过、翻页了）就拒绝，重新改一次。

**两种模式**（v1.40.0，页顶一枚分段钮）：**✏️ 改稿**就是上面说的这套，对着一楼聊、聊完改好替换、替换后清空。**🍉 蛐蛐**是和朋友一起追剧：一把聊天一本账，不按楼分、不自动清，跟着剧情一楼一楼走——她永远对着最新一楼，新楼落地画面上会提示「剧情走到 #N 了，下一句她就能看到」，你那句话发出去时前面自动标「（剧情走到 #N 了）」，她先看新楼再接着聊；画面按楼号打分隔线，一眼看出哪段话是追到哪一楼时聊的。蛐蛐人设另有一份出厂：陪看的朋友，蛐蛐主角、替配角不值、嗑或拆、押下一步、翻旧账，有立场能站队，但每句落在具体情节上；只聊不改稿（「改好给我」在这个模式里收起）。记录最多存 300 句，发请求时全带（v1.42.0 起不再只带最近 40 句）。两种模式的人设各一份，都能改、都能恢复出厂。

**名字与人格**（v1.50.0）：掌灯里和你说话的那一位，默认是小红霞，也可以是别人。「🎭 小红霞的人设」一节最上面有两栏：**名字**（留空＝小红霞）和**人格**（她是谁、怎么跟你说话；留空＝出厂的小红霞）。想让爱人、闺蜜、或者列夫·托尔斯泰陪你看这部小说，就照着写。填了以后，面板上的称呼（分节标题、对话里的署名、蛐蛐小窗的标题、状态行）跟着名字换，她在对话里也这样自称。名字和人格管的是「她是谁」；下面两份人设管的是「改稿、蛐蛐时她做什么」，换了人格也照做，一般不用动。执笔位（真正落笔改稿的那一次请求）不带人格：稿子照原文的文笔写。点「变回小红霞」两栏清空。只管掌灯，剧场和两位导演不受影响。

**自动蛐蛐**（v1.41.0，可选，默认关）：聊天区勾上「新楼落地自动蛐蛐一句」，每楼落地、字出完之后，她自己像刷到更新似的随手发一条 60 字以内的吐槽，弹个小窗，**不自动关，看完点「朕已阅」**（v1.41.3；没看的排队，一条条看），同时写进蛐蛐记录（标「自动」），你随时能接着回。每楼一次，重 roll 算新一版会再来；楼还在出字就等；「小红霞正在运行」总开关关着就不来；走聊天位的 API，一楼一次请求，**花钱**，自己掂量。不管当前在改稿还是蛐蛐模式都生效，账记在蛐蛐那本。勾选底下一枚「🍉 现在蛐蛐一句」，不等新楼、不管勾没勾，立刻对最新一楼来一句（v1.42.0）。没发出来会在蛐蛐记录里留一行原因。

**对话框卷到最新**（v1.41.9）：重开浮窗、切页、收起再展开聊天抽屉，对话框都停在最新一句；对话框底下两枚键「↑ 回顶」「↓ 回底」只管对话框，翻旧账翻远了一键回来。

**两个 API 位**：聊天位默认借统筹的，执笔位默认跟聊天位；都能改借情感导演 / 展开 / 小眼睛的，或自己填。**API 预设**（v1.46.0，和导演页那套一样）：聊天位、执笔位、剧场位各有一行「API 预设」——下拉一选就切过去（这一位自动改成「自己填」，地址、钥匙、模型一起填好），不用每次敲 key。三个位共用一份预设单，在哪一位存的另外两位都能选；导演和抽卡那边已经存好的预设也列在下拉里，直接选就行。填好后写个名字点「保存」存成预设，同名再存是更新，「删除」要点两下、只删预设单里那一条。想让改出来的文风和前后楼一致，执笔位填主聊天用的那个模型（Gemini、DS 都行），和你顶嘴的聊天位接 Claude 这类——讨论归讨论，下笔归下笔。温度默认 0.8，聊天与改稿同用。新增 test_lamp.js 113 项。

### 导演不抢半楼（v1.38.5）

到了触发层数、这一楼还在往外出字，导演却已经开始分析了，分析出来的方向跟这楼最后写成的样子对不上。原因是酒馆发"开始生成"时小红霞会升旗等着，但旧版 3 分钟没等到"生成结束"就强制降旗开工——会思考的模型、慢中转站一楼出 5 分钟很平常，保险丝一烧导演就拿半楼开分析，稿子还往正在流式的楼里塞、被下一截字冲掉。现在降旗前先看两样证据：酒馆的停止按钮还亮着没有，最后一个助手楼的字数最近还在不在长；两样都没有才算真的写完。就算"生成结束"事件完全没收到，只要楼里字数还在变就等，停下来至少安静 4 秒才读。事件齐全的正常回合一点不多等，节奏照旧。等生成写完再挂稿的上限从 3 分钟放到 20 分钟。新增 test_settle.js 13 项。

### 中途换聊天不串稿（v1.38.4）

导演等 API 的几十秒里你换了角色卡，以前回来的稿子会照样挂进新聊天的最后一楼，还会存成新聊天的常驻浮动稿，上一张卡的情感指导就这么贴到这张卡耳边不走了。现在导演开跑时记下自己在哪把聊天，稿子回来先对表：不是同一把就不挂、不贴、不存，状态行说明"中途切换了聊天"，稿子留在预览框里想用可以手动复制；换聊天的那一刻如果请求还挂着，直接掐掉不等了。自动触发那一整趟（读全量、抽卡检查、情感、统筹）每个等待点都对表，换了聊天就整趟作废，旧聊天的楼数和基准线不会拿去给新聊天开导演；抽卡小能手问小眼睛择池、择卡期间换聊天同样作废（展开那一段早有防护）。新增 test_switch.js 27 项。

### A 社官网直连（v1.38.0–1.38.1）

两位导演、择池／择卡、剧情展开的 API 地址直接填 `https://api.anthropic.com`、钥匙填官网 `sk-ant-…` 就能用，模型名填 `claude-opus-5-5` 这类官网模型 ID（点「加载模型」也能拉到列表）。此前填官网地址一律「Failed to fetch」：小红霞是在浏览器里直接发请求的，A 社对浏览器来的请求先做 CORS 预检，请求头里没有 `anthropic-dangerous-direct-browser-access: true` 就直接拒掉，钥匙对不对、余额够不够根本走不到。现在凡是域名落在 anthropic.com 的地址都自动带上这枚头；聊天走 A 社的 OpenAI 兼容口 `/v1/chat/completions`（仍是 Bearer），模型列表 `/v1/models` 是原生口，改用 `x-api-key` + `anthropic-version`。中转站、DS、Gemini 兼容口等其余地址的请求头一个字都没变。新一代 Claude（Opus 4.7 起、Sonnet 5 起、Fable 5 起）不再收 `temperature`，发了直接 400「temperature is deprecated for this model」；官网直连一律不送这个参数，中转站后面挂着这些模型的，见到这句 400 会摘掉再试一次，别家模型照旧送（v1.38.1）。注意：这枚头的名字里就写着 dangerous，意思是钥匙在你自己的浏览器里发出去，和填中转站钥匙是同一回事，别把酒馆页面给别人用。

### 剧情展开推进（v1.34.0–1.34.3）

### 浮窗的版式（v1.49.0–1.50.1）

浮窗是「留白」版式：字标用高反差衬线、中文用细字重；总开关和页签不套胶囊；收起的分节是目录式的一行，展开才是一张卡；状态条是左边一道细霞线；台头一道水纹，小红珠周围几圈涟漪。v1.50.1 起这就是浮窗固定的样子，没有开关，不退回旧版式。

### 导演稿怎么贴在耳边（v1.52.0）

两位导演的稿除了挂在楼里，还会贴在对话末尾跟着走（「贴耳模式」）。这一版改了四处，都是冲着「导演帮倒忙」去的：

- **各占一格**。以前全聊天只有一格，谁后上岗就把对方的顶掉：情感导演一来，统筹的安排就没了。现在两位各有一格，同时贴着，新的那份排在后面。嫌两份加起来太长的，在「进阶开关」里取消「两位导演的稿都贴着」，就回到只贴最新一份、后来的顶掉先来的。
- **「这几楼」的话到期就撤**。一份稿里有两类话：管接下来几楼的（先降温、让谁出场），和要一直守的（人设边界、没收的线）。前一类挂够 3 楼自动撤下，只留后一类常驻。以前整份一直挂到下一次导演上岗，戏早就走过那个点了，它还压着。几楼撤可以在「进阶开关」里改，填 0 就和以前一样整份常驻。
- **允许「维持」**。戏走得好好的，导演可以只回一句维持。这时不往楼里挂稿，也不换耳边那份，只在跟组记录里记一笔。
- **出厂提示词重写**。情感导演先分清「主模型演法不同但从角色出发说得通」和「真出戏」，前者顺着找补，后者才修正；提醒不许只说别做什么，要写成「别这样 → 换成这样」；每条意见要落到一个演得出来的动作。统筹多了维持的出口和「连着两次没执行就换一种安排」。

认哪段是长期的，靠稿里的小标题：情感导演的【长期边界】（旧格式的【人设边界】也认）、统筹的【收线】。所以自己改过提示词的人，只要还留着这些小标题，一样能分；认不出来的，整份照旧常驻。【验收】【判断】两栏是给人看的账，只留在楼里，不贴到主模型耳边。

出厂提示词只升级「和上一版出厂逐字相同」的：你改过哪怕一句，就一个字都不动。想用新的，在预设里点恢复默认，或者照着 CHANGELOG 里的全文自己并进去。

两位导演的请求改为流式（`stream: true`）。会思考的模型接在导演位上常报错，是因为非流式要等整段思考跑完才回第一个字节，中转站的空闲超时先把连接掐了；现在逐块接收、只把正文拼进稿子、思考只计字数不进稿，状态行会实时写「模型思考中，N 字」／「已收到 N 字」。120 秒超时改成「两块之间」的空闲闸，思考再长也不掐，真断流才报「流式接收中断」。服务端不支持流式、回整份 JSON 的照常能用。若某个中转站对流式请求直接报错，共享设置里把「流式接收导演稿」关掉即可，回到老的整份接收，默认是开的。小眼睛（择池／择卡）那几路不变。

### 放大编辑（v1.26.0）

浮窗和内嵌抽屉里每个文字框右上角都有一枚 ⛶，点开整屏编辑（手机全屏、电脑大弹窗），改完点确定回填，自动保存照常；取消或 ESC 不动原文，Ctrl/⌘+Enter 等于确定。

### 本包配色：琉璃暗河（v1.25.0）

浮窗与酒馆内嵌抽屉整套换皮，只动视觉不动功能：暗河（🌙）是墨靛玻璃面、顶部一抹霞光、卡片带一线内高光；朝霞（☀️）是瓷白纸面、淡粉淡蓝晕、砚蓝墨字。主动作按钮（分析／挂稿／试抽）改为实色霞光渐变，次级按钮退为玻璃描边；输入域收窄一档并加内阴影；开关换成带投影的胶囊；页签成分段控件；计数卡的数字用香槟金。触控命中区与右缘安全缝原样保留。

## 一、剧情小风铃是什么

治长上下文剧情塌缩的土方子：每 N 个助手正文轮次，向模型耳边投一张**"发生了一半的事"**——门房的口信、没熄火的车、被撕走的账页。卡通过独立扩展提示词通道常驻注入（不占楼层，藏楼/摘要洗不掉），下一张到点自动替换。

机器全瞎：数楼、掷骰、贴耳，三个动作，零 API、零延迟、零开销。聪明不在机器里，在卡里——你写卡的时候把智能一次性预付了。

### 两分钟上手

1. 打开 Arrebol D 面板 → 「🎴 抽卡」页 → 勾选**启用剧情小风铃**
2. 出厂自带「通用」卡库（意外/转折/伏笔/代价/外力/狗血六池），到点即投
3. 想换节奏拖 N 滑杆（1–20 楼，默认 5）；关键场景勾**暂停投卡**（按聊天记忆，暂停期间耳机静音）
4. 点**试抽一张**可预览手感——不入投卡史、不注入、不产生费用

### 两种模式

- **盲抽**（默认）：两段抽——先各卡池均等随机，再池内均匀随机＋冷却（最近 M 张不复用，默认 8、最多 32，填 0 就是没有冷却；单池卡数不足时自动降冷却，永不死锁）。天马行空档。
- **择卡**（v1.23.0）：按仓库均摊摸出若干候选，**连卡面一起**给 DS，让它挑最贴合此刻的一张——**必须选一张，没有「都不选」这个出口**（v1.23.0 给过弃权位，结果模型一路空过，一张不投，v1.23.1 拆除）。治的是"池选对了、池内那张不贴合"。NSFW 候选只给标签不给卡面（`【NSFW·池名】（卡面不外传）`），准入仍由双向硬门把关。答复只认数字；越界、夹带解释一律降级盲抽。
- **择池**：接一个便宜模型（推荐 DeepSeek，独立 API 位）当**小眼睛**（这个位置接 DeepSeek、Gemini 或你自选的任何模型都行，面板与日志里一律叫它小眼睛；地址填到版本段即可，`/v1`、`/v1beta/openai`、`/api/paas/v4` 这类都认得。小眼睛的答复额度是 200 个 token，答复本身只要几个字，余量是留给会思考的模型的；思考特别长的模型仍可能回空、被记成"答复无效"而降级盲抽，日志会写明原因，那就换不思考的模型或在服务商侧关掉思考）——**只看卡池名单点池，看不到任何卡面**，池内仍然盲抽。答复多一个字作废。

  择池那次调用喂给 DS 的语境按这个顺序：**【刚刚这一楼】→【再往前几楼】→ 卡池名单 → 最近已投 →【整体调性】**。此刻的氛围只认第一段；前几楼只用来看这股势头是在持续还是已经收场；角色卡与世界书压在最后并截到 2000 字，只用来判断某类情节允不允许发生，**不作为此刻的依据**。

  **必须选一个**：名单里没有「都不选」。即使此刻没有特别贴合的，也要挑最不打断当下的那一个。（v1.23.0 曾给过弃权出口，模型一路走出口导致完全不投卡，v1.23.1 拆除。）

  **防惯性**：同一卡池被连点第 3 次，改在**同一仓库内**换池。情欲场面里连点同一个 NSFW 池正是应该的，踢去全仓库盲抽反而会拿无关卡打断场面。

  **降级会出声**：超时（8s）、解析失败、报错一律当场降级盲抽，抽卡器永不停摆；此时 **NSFW 库一律不参与**（DS 挂了＝没人判准入条件，默认不准入），状态行会直说「⚠ 上一张是 DS 没应答时随机给的」。两个例外（v1.29.4）：只开 NSFW 仓库时不闸——那是你自己的配置，闸上就是永远空过；小眼睛被**内容审核打回**（DeepSeek「Content Exists Risk」一类）不算没应答，而是它看了这一楼后拒答，说明这一楼正是情欲场面，按门已开处理、在 NSFW 库内盲抽，状态行会直说。

  **名单只有一个池／候选只有一张时不问小眼睛**（v1.29.4）：没什么可挑，直接投，省一次调用，也不给审核打回的机会。

### 三个仓库

抽卡器面前摆三格，各自独立勾选：

| 仓库 | 干什么 |
|---|---|
| **专属剧情库** | 配角色卡——写这个角色独有的事（前世债、师门旧账、他特有的毛病） |
| **通用库** | 打底——车票、口信、钥匙这类哪朝哪代都能落的事 |
| **NSFW 库** | 单独一格，默认停用，内容由你自己填 |

> **NSFW 库的准入只由择池模式把关**（双向硬门：此刻确有情欲张力在持续 **且** 故事整体调性允许，两条都满足才选它，任一不满足就当它不在名单上）。盲抽模式没有眼睛，点亮就是 1/N 硬掷——这是明码标价的取舍，不是 bug。择池失败降级时 NSFW 一律不参与，但有两个例外（见上文「降级会出声」）：只开 NSFW 仓库时不闸，小眼睛被审核打回时按门已开处理。另一个边界要说清：**只开 NSFW 仓库时，名单里就只有 NSFW 池**，双向硬门无门可把、也不再注入（v1.29.4 前会注入，与「必须选一个」自相矛盾，模型只能答废话）；只有一个池时连小眼睛都不问，直接投——这是用户自己的仓库配置，插件不替用户做选择。

**仓库数即权重**：启用哪几格，就在哪几格之间均等掷。专属库只有 1 个卡池、通用库有 5 个，专属库照样占一半出场——这是三段抽的第一段保证的，不会被池多的一边淹掉（桩测两万次实测 50.2%）。

三格都是"选一副卡库挂上去"，同一副库可以挂在不同聊天的不同格里。换聊天各记各的，账号级留一份默认，新聊天开局自动继承。

### 卡库仓储

- 格式祖传：`## 卡池名` 一行开池，一行一张卡，`//` 开头是注释，空行随意。**即改即生效。**
- 卡库按名字管理；编辑区选一副改，改完**保存**（新建或更新）／**重命名**／**删除**。
- 双向门：导入 / 导出 `.txt`/`.md`。**导入时可直接选落点**——挂进哪个仓库，导完就能用；同名不覆盖，自动另开一副。
- 卡面里可以写 `{{user}}`、`{{char}}` 等宏，投卡时替换成当前名字。

### 卡面家法

一张卡 = 一件发生了一半的事，三特征缺一不可：

- **具体**：有人有物有时刻
- **悬置**：谁 / 为何，卡不说，留给演员说
- **可嫁接**：无专名，什么局都能落（专名由统筹在场上现铸）

「门房捎来一句口信：三天前就该到的人，今晚到了」——合格。
「现在发生一个转折」——不合格。

nsfw 池另加一条：写"把房间弄斜的一件事实"——灯没关、门没锁、话说了一半；不写动作说明书。

## 二、红霞转岗：统筹

推剧情、保新鲜这份匀速活移交给了抽卡器——该由"物"干的不再由"评"干。红霞升职**统筹**，四职一次调用打包：

1. **派人**：NPC 进出场调度；复活冷板凳角色；给无专名的事件卡选角
2. **顺场**：转场衔接与流畅度
3. **收线**：盘点伏笔与已投事件卡，点名哪条该兑现——撒出去的钩子不许无限堆积
4. **急诊与验收**：NG 会诊照旧；评估此前指导执行情况

输出纪律（硬性）：带名字带条目——「让老周把口信送到」合格，「推进剧情」退回重写。统筹的采买清单里含**投卡史**（最近 5 张：卡池/卡面/楼层/模式），账房盘账看得见牌桌。

例行巡逻默认关；开启时默认每 20 楼。日常节奏：抽卡器匀速开门，统筹低频收线＋NG 触发＋手动，贵重模型少开火，账单反而降。

存量说明：若你的剧情导演预设从未改过默认值，升级后自动换为统筹说明书；自己改过的预设一律不动。

### 导演的记忆跟着聊天走（v1.24.0）

两位导演的进度（还有几楼触发）、跟组记录（自己此前下过的指导）、常驻贴耳稿、放养标记，都存在**聊天文件**里（`chat_metadata`），跟抽卡模块一样——换设备、换网址、清浏览器缓存，导演都不失忆；浏览器里只留一份镜像做灾备。老存档第一次打开时会从旧位置搬家一次，旧位置原样保留，回退到 1.23 仍能用。

## 五、卡的生命周期

以前一张卡从投下到被顶掉，全程都挂着「必须发生」——第一楼就写完的事，后面几楼还在耳边催，只能反复强调或假装没看见。现在它有三段命：

| 阶段 | 耳边说的话 | 怎么进入 |
|---|---|---|
| **必须发生** | 以下事件已然发生，织入正文 | 刚投下 |
| **已发生的背景** | 此事已经发生过，可以被提及，但不必再推进 | 挂过 N/2 楼自动（半衰期档） |
| **只说了一次，已撤下** | （耳边清空，留白到下一张） | 挂满一层自动（只说一次档） |
| **已结案** | （耳边清空） | 手动点撤下，或 DS 判定已兑现 |

### 生命节奏三档（v1.20.0）

面板上「这张卡在耳边待多久」一个下拉，三选一：

| 档位 | 行为 | 治什么 |
|---|---|---|
| **半衰期**（默认） | 前 ⌈N/2⌉ 楼「必须发生」，之后换成「已发生的背景」继续挂着 | 原样，老用户升级后行为不变 |
| **只说一次** | 只挂一层，说完自动撤下，耳边留白 N−1 楼，第 N 楼再给新卡 | **模型反复复述同一段剧情** |
| **常驻** | 一直挂到下一张来换，不降级 | 等价于旧版关掉半衰期 |

**为什么需要「只说一次」**：贴耳注入每次生成都会把同一张卡再念一遍——N=10 就是连着念十遍「必须发生某某事」。模型复述好几轮不是它笨，是我们真的念了好几遍。半衰期只放软后半程的语气，念的次数一次没少；这一档把次数直接压到一遍。那一层模型没接住就算了。DS 兑现判定在这档跳过，不产生费用；投卡史记「只说了一次」，不冒充已兑现。

老存档自动迁移：原来勾着半衰期 → 落到「半衰期」；原来关着 → 落到「常驻」。

- **半衰期**：纯本地换一次文本，零 API、零延迟。N=5 就是第 3 楼自动退为背景。
- **一键结案**：读到卡里的事落地了，点「✓ 这张已兑现，撤下」。**基准线不推进**——下一张仍按原节奏来，中间那几楼是留白，让剧情喘口气。
- **DS 自动判定**（默认关）：到半衰期时问一句「兑现没」，只认「是」/「否」，答是就自动撤下。每张卡最多多一次调用，跟择池同频。**判不了就按未兑现降级，绝不误撤。** NSFW 库的卡不问（卡面不出门），到半衰期直接降级为背景。
- **投卡史带状态**：● 挂载中 / · 已退为背景 / ○ 只说了一次已撤下 / ✓ 已兑现，统筹收线时看得见哪条还欠着。

### 信封两段式 + 预设

信封拆成前半程与后半程两套文本，按名管理，出厂四套：**标准**（默认）、**强硬**（加粗禁止复述，对付爱复读的模型）、**轻柔**（只给氛围不给指令，对付被硬指令带跑偏的模型）、**看时机**（v1.23.0）。

「看时机」值得单独说：标准信封写的是「以下事件已然发生。织入正文」——等于命令模型**这一楼就得用**。一张温情卡撞上正在吵架的一幕，崩就崩在这一句。「看时机」保留「必须发生」的分量，只把时点的决定权还给写故事的模型：*若此刻场面不适合它进场，就让它先在背景里发酵，等一个合适的时机再织入正文*。老用户升级后会自动补上这一套（改过的旧信封一字不动；自己删掉的不会复活）。
下拉切换立即生效；改了文本再点保存就写进当前这套。
