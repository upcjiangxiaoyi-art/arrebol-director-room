## 一、剧情小风铃是什么

治长上下文剧情塌缩的土方子：每 N 个助手正文轮次，向模型耳边投一张**"发生了一半的事"**——门房的口信、没熄火的车、被撕走的账页。卡通过独立扩展提示词通道常驻注入（不占楼层，藏楼/摘要洗不掉），下一张到点自动替换。

机器全瞎：数楼、掷骰、贴耳，三个动作，零 API、零延迟、零开销。聪明不在机器里，在卡里——你写卡的时候把智能一次性预付了。

### 两分钟上手

1. 打开 Arrebol D 面板 → 「🎴 抽卡」页 → 勾选**启用剧情小风铃**
2. 出厂自带「通用」卡库（意外/转折/伏笔/代价/外力/狗血六池），到点即投
3. 想换节奏拖 N 滑杆（1–20 楼，默认 5）；关键场景勾**暂停投卡**（按聊天记忆，暂停期间耳机静音）
4. 点**试抽一张**可预览手感——不入投卡史、不注入、不产生费用

### 两种模式

- **盲抽**（默认）：两段抽——先各卡池均等随机，再池内均匀随机＋冷却（最近 M 张不复用，默认 8；单池卡数不足时自动降冷却，永不死锁）。天马行空档。
- **择池**：接一个便宜模型（推荐 DeepSeek，独立 API 位）当"小眼睛"——**只看卡池名单点池，看不到任何卡面**，池内仍然盲抽。答复多一个字作废；超时（8s）、解析失败、报错一律当场降级盲抽，抽卡器永不停摆。防惯性：同一卡池被连点第 3 次，机器强制从其余卡池盲抽。

### 三个仓库

抽卡器面前摆三格，各自独立勾选：

| 仓库 | 干什么 |
|---|---|
| **专属剧情库** | 配角色卡——写这个角色独有的事（前世债、师门旧账、他特有的毛病） |
| **通用库** | 打底——车票、口信、钥匙这类哪朝哪代都能落的事 |
| **NSFW 库** | 单独一格，默认停用，内容由你自己填 |

**仓库数即权重**：启用哪几格，就在哪几格之间均等掷。专属库只有 1 个卡池、通用库有 5 个，专属库照样占一半出场——这是三段抽的第一段保证的，不会被池多的一边淹掉（桩测两万次实测 50.2%）。

三格都是"选一副卡库挂上去"，同一副库可以挂在不同聊天的不同格里。换聊天各记各的，账号级留一份默认，新聊天开局自动继承。

### 卡库仓储

- 格式祖传：`## 卡池名` 一行开池，一行一张卡，`//` 开头是注释，空行随意。**即改即生效。**
- 卡库按名字管理；编辑区选一副改，改完**保存**（新建或更新）／**重命名**／**删除**。
- 双向门：导入 / 导出 `.txt`/`.md`。**导入时可直接选落点**——挂进哪个仓库，导完就能用；同名不覆盖，自动另开一副。
- 卡面里可以写 `{{user}}`、`{{char}}` 等宏，投卡时替换成当前名字。

### 卡面家法

一张卡 = 一件发生了一半的事，三特征缺一不可：

- **具体**：有人有物有时刻
- **悬置**：谁 / 为何，卡不说，留给演员说
- **可嫁接**：无专名，什么局都能落（专名由统筹在场上现铸）

「门房捎来一句口信：三天前就该到的人，今晚到了」——合格。
「现在发生一个转折」——不合格。

nsfw 池另加一条：写"把房间弄斜的一件事实"——灯没关、门没锁、话说了一半；不写动作说明书。

## 二、红霞转岗：统筹

推剧情、保新鲜这份匀速活移交给了抽卡器——该由"物"干的不再由"评"干。红霞升职**统筹**，四职一次调用打包：

1. **派人**：NPC 进出场调度；复活冷板凳角色；给无专名的事件卡选角
2. **顺场**：转场衔接与流畅度
3. **收线**：盘点伏笔与已投事件卡，点名哪条该兑现——撒出去的钩子不许无限堆积
4. **急诊与验收**：NG 会诊照旧；评估此前指导执行情况

输出纪律（硬性）：带名字带条目——「让老周把口信送到」合格，「推进剧情」退回重写。统筹的采买清单里含**投卡史**（最近 5 张：卡池/卡面/楼层/模式），账房盘账看得见牌桌。

例行巡逻默认关；开启时默认每 20 楼。日常节奏：抽卡器匀速开门，统筹低频收线＋NG 触发＋手动，贵重模型少开火，账单反而降。

存量说明：若你的剧情导演预设从未改过默认值，升级后自动换为统筹说明书；自己改过的预设一律不动。

## 四、v1.11.0 修了什么

- **改不了库名 / 写卡被抹**：周期刷新会覆盖正在输入的输入框。现在编辑区脱离周期刷新链，且任何写值都跳过正在打字的控件（双保险）。
- **暂停勾不上**：写入后回读校验，成功与否直接写在面板上；存档未就绪会自动重试，不再默默失败。
- **删除卡库后仍显示原名**：删除后仓库槽自动置空并提示重选；文案不再误导。
- **状态行看不全**：点一下展开／收起，最近一张卡的全文可见。
- **🔧 自检**：点一下把当前聊天的全部运行状态印在面板上（三仓库卡数、存档通道、暂停状态、基准线、耳机挂载字数）。手机上没有控制台，这就是控制台。

### v1.11.1 补丁

iOS 上三个仓库的勾选框点不动、下拉打不开、模型下拉打不开——同一个病根：控件变动时立刻落盘，落盘触发的刷新会重写下拉的选项列表，而 iOS 的原生选择器一旦发现选项被改写就当场关闭。三道药：选项没变绝不重写 DOM、刚点过的控件 1.5 秒内免疫任何刷新、落盘改为防抖。导入/导出按钮也改成网格排布，窄屏不再被挤出视野。

### v1.11.2 补丁

下拉要点两次才选得上：上一版的保护锁是在"选完"（change）那一刻才上的，而原生下拉是在**手指按下那一刻**弹出的，中间那段空档无人看守；加上首次渲染的选项没有签名，第一次刷新必然重写一次 DOM，正好撞在弹出期间，第一次选择就被吞掉。改为手指按下（pointerdown/touchstart/mousedown）即上锁，并让选项签名随 HTML 一起生成，杜绝首次无谓重写。编辑区下拉也改为渲染即填充，不再是空壳等刷新。

## 五、v1.12.0 卡的生命周期

以前一张卡从投下到被顶掉，全程都挂着「必须发生」——第一楼就写完的事，后面几楼还在耳边催，只能反复强调或假装没看见。现在它有三段命：

| 阶段 | 耳边说的话 | 怎么进入 |
|---|---|---|
| **必须发生** | 以下事件已然发生，织入正文 | 刚投下 |
| **已发生的背景** | 此事已经发生过，可以被提及，但不必再推进 | 挂过 N/2 楼自动 |
| **已结案** | （耳边清空） | 手动点撤下，或 DS 判定已兑现 |

- **半衰期**：纯本地换一次文本，零 API、零延迟。N=5 就是第 3 楼自动退为背景。
- **一键结案**：读到卡里的事落地了，点「✓ 这张已兑现，撤下」。**基准线不推进**——下一张仍按原节奏来，中间那几楼是留白，让剧情喘口气。
- **DS 自动判定**（默认关）：到半衰期时问一句「兑现没」，只认「是」/「否」，答是就自动撤下。每张卡最多多一次调用，跟择池同频。**判不了就按未兑现降级，绝不误撤。**
- **投卡史带状态**：● 挂载中 / · 已退为背景 / ✓ 已兑现，统筹收线时看得见哪条还欠着。

### 信封两段式 + 预设

信封拆成前半程与后半程两套文本，按名管理，出厂三套：**标准**（默认）、**强硬**（加粗禁止复述，对付爱复读的模型）、**轻柔**（只给氛围不给指令，对付被硬指令带跑偏的模型）。下拉切换立即生效；改了文本再点保存就写进当前这套。

## 六、v1.13.0 放养模式

**手动放养、自动归队。**每个导演页多一个「放养」按钮（双击确认防误触，双导演各自独立）：

- 点下去：本类型当前贴耳稿立即撤下——全楼层的正文注入块和常驻浮动稿（若挂的是本类型）一并撕掉，另一类型的稿原地不动
- 轮换计数**不重置**，基准线体系零接触，继续照常往下走
- 放养期间**零生成、零 API**——导演是真下班了，不是生成了不用
- 到达下一个换稿点 → 自动触发正常生成并挂上 → 放养自动结束，弹一句「已归队」

放养时长天然可控：第 3 楼点能野 7 楼，第 9 楼点只野 1 楼——想多野就早点点，没有第二个参数要设。野完还想接着野，归队后再点一次就是。

状态栏放养期间显示：**放养中 · 距下次接管还有 X 楼**——免得野久了忘了它还会回来，突然被管上莫名其妙。

归队的唯一判据是「本类型稿子真正挂上」：自动触发注入、手动注入都算。若自动触发没开（无换稿点可归队），状态栏会提示点「直接分析」或「手动注入」即归队。

### v1.13.1 补丁：DS 视野随节奏走

兑现判定和择池的回看范围原先钉死 4/6 轮——N 调大后，卡在视野外兑现的事 DS 看不见，只能答"否"。现在跟节奏挂钩：**兑现判定回看 ⌈N/2⌉+2 轮**（卡挂了多少楼就回看多少楼），**择池回看 N+2 轮**（上张卡以来的正文都算数）。下限保持旧默认不缩水（N 小的人一切照旧），上限封 12 轮 / 8000 字，开销和延迟不跑飞。提议：ripple。

### v1.13.2 补丁：口径免疫（修复"每点一下启动正则导演就上岗一次"）

病灶：导演的楼层计数原先"数有正文的楼"——预设正则一开一关会把某些楼的文本在"空/非空"之间扳来扳去，总数随开关横跳，导演把口径跳变误当"到点"，于是每点一下启动正则就分析注入一次（报告：MoMo）。

两刀：**① 数楼不数字**——楼层存在即计数，不看当前渲染文本，任何美化/正则/隐藏楼层都扳不动节奏；**② 常任守卫**——"差值离谱（超过间隔+20）只对齐不注入"从每会话一次改为常任生效，活人聊天到不了这种差值，到了必是口径被外力扳动。API 断线攒的补拍带 pending-retry 标记，照常放行。

升级后首次检查若发现旧口径与新口径差值大，守卫会静默贴齐一次（控制台有 warn 日志），不会多注入。

## 七、v1.14.0 改头换面第一刀

UI 分层重构第一步（产品：ripple），功能零变化，全部按钮 ID 原封不动：

- **分析按钮二合一**：「直接分析」「补充指令分析」合并为一个「分析」——补充指令框空着就是普通分析，填了字导演就带着你的要求分析。少一个按钮，少一个概念。
- **三层收纳**：共享设置分为常用层（复盘范围/角色卡要点/注入方式/两个圆开关）→「⚙️ 进阶开关」抽屉（跟随注入/跟组/NG，默认已调好）→「🔧 校对与诊断」抽屉沉底（检测上下文等，排查问题才用）。抽屉开合状态有记忆，这次收起下次还是收起。
- **形状语法**：常用层开关是圆的（随便点），抽屉里的开关是方的（想想再点）。手指自己就懂，不用读说明。
- **横幅瘦身**：一键开关从大板砖变细胶囊，就绪说明降为一行小字。
- **右缘留缝**：面板右侧多留一指缝，iOS 侧滑返回不再误触。

### v1.14.1 补丁：人话文案包

全部按钮与开关说明换成直白话（逐条经 ripple 批签）：复盘范围→导演回看多少楼；注入方式→导演稿怎么放进聊天；跟随注入→贴耳模式；本地测试→试运行（不花钱）；补充指令→想对导演说的话；校准当前进度→重新对表；统筹例行巡逻→让统筹定期来看一眼大局；手动注入→把这份稿挂上。「放养」「NG 检测」等本就自解释的保持原样。

### v1.14.2 补丁：命中区收身

开关的点击区原先横贯整行——文字右边那一大段空白也能点，容易误触。现在点击区只包住圆圈+文字本体，空白就是空白（报告：ripple）。
